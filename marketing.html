¿Cuántos hogares distintos aceptaron una oferta y a cuáles podríamos considerar para el siguiente contacto?

Qué encontramos

Encontramos 18 aceptaciones de 9 hogares. Para el siguiente contacto propusimos 5 hogares con hijos, gasto de al menos 600 unidades monetarias (UM) y sin queja registrada. Juntos acumularon 3,800 UM de gasto.

Hasta dónde llega el dato

La muestra describe respuestas registradas. Para estimar el efecto de una oferta sobre las compras necesitaríamos comparar hogares expuestos con un grupo de referencia.

PROCESO DE ANÁLISIS

Cómo lo trabajamos

Clasificamos los hogares por gasto y documentamos los criterios de contacto. Para medir el alcance contamos cada hogar una sola vez, aunque hubiera aceptado varias campañas.

PREPARACIÓN

Trabajamos los registros

Construimos el segmento de gasto e incluimos el valor exacto de 600. Cruzamos ese criterio con hijos en el hogar y ausencia de quejas para formar la lista comercial.

Python · pandas
def clasificar_gasto(total_gasto):
    if total_gasto >= 600:
        return "Desde 600"
    return "Menor a 600"

df_preparado_mk["SegmentoGasto"] = (
    df_preparado_mk["TotalGasto"].map(clasificar_gasto)
)
CONSULTA

Contrastamos el resultado

Seleccionamos los identificadores únicos con alguna aceptación antes de contar hogares. Así, un hogar que aceptó dos ofertas entra una sola vez en el conteo.

SQL · SQLite
SELECT COUNT(*) AS HogaresAceptantes
FROM (
    SELECT DISTINCT ID FROM respuestas_mk
    WHERE Aceptada = 1
) AS aceptantes
MODELO Y MEDIDAS

Llevamos la pregunta al informe

La práctica relaciona Hogares y Campanas con Respuestas. Al sumar la bandera de aceptación podemos comparar ofertas y separar el número de respuestas positivas del número de hogares alcanzados.

Power BI · DAX
Aceptaciones = SUM(Respuestas[Aceptada])
